## 按人数配配置：内存比核心数更容易不够

Minecraft 和 Valheim 的主逻辑都压在一个主线程上，CPU 单核频率对帧率和 TPS 的影响比核心数大，所以这几个机型清一色是高主频 U。真正容易翻车的是内存。

以 Valheim 为例，服务端空载就要占 1.8GB 到 2.4GB，每个玩家所在的活动区域再额外吃 100MB 到 300MB。照这个算：

| 同时在线 | 建议配置 | 说明 |
| --- | --- | --- |
| 2-4 人 | 2 核 4G 起，上行 3Mbps | 4G 是底线，2G 跑起来会一直读写交换 |
| 5-10 人 | 4 核 4G 以上，上行 5Mbps | 基地建得越大，内存越吃紧 |
| 10 人以上或重度 Mod | 8G 内存起 | Valheim Plus、BepInEx 这类框架每个都额外占内存 |

端口是最容易漏的一步。Valheim 要放行 **2456、2457、2458 三个端口，TCP 和 UDP 都要通**，少放一个就连不上。幻兽帕鲁默认走 **UDP 8211**。买之前在控制台的安全组里确认端口能开，不然服务端日志显示启动成功，游戏里照样连不进去。

还有一条主机玩家会踩的坑：PS5、Xbox 没法通过 IP 直连，只能从公共服务器列表里进，也不支持 Tailscale 这类组网工具，想半私密只能设服务器密码。这条限制对自建服和买现成套餐一样成立。

## 固定计费和动态计费，哪种更省

固定计费是月付一口价，配置和账单都是确定的。

动态计费把基础租金压低，再按 CPU 实际使用量每天结算一笔“CPU 电量费”。私服的使用曲线通常是白天没人、晚上满员，这种负载用动态计费确实能省下一截，同机型价差能到 20 到 85 元一个月。

代价有两个。账单不固定，某天开活动人多，那天的电量费就上去了。账户余额扣光后服务器会暂停，跑长期服的话账户里要留够至少一个月的量。

判断规则很简单：在线人数稳定、天天有人挂机，选固定计费；只有晚上和周末有人、寒暑假集中开，选动态计费。

## 常见问题

**Q：面板游戏云能开幻兽帕鲁或英灵神殿吗？**
不能。一键开服列表目前主要是 Minecraft、泰拉瑞亚、饥荒。帕鲁和 Valheim 要选 VPS 形态，自己用 SteamCMD 部署，Windows 和 Linux 都支持。

**Q：NAT 档 15 个端口转发够用吗？**
开一个 MC 服够。多开几个服、或者要让服出现在公共列表里被陌生人加进来，就得换独立 IP 档。

**Q：动态计费会不会某天突然扣很多？**
按当天 CPU 实际使用量结算，负载高扣得多。余额扣光服务器会暂停，不会透支。长期跑的话账户里留够一个月的量。

**Q：湖北机房为什么用不了券？**
当地有最低限价政策，不支持优惠券。想用新人 5 折的，选其他机房。

**Q：台式机自己开服不行吗？**
行，但主机一关全员掉线，家用宽带多数没有固定公网 IP，高峰期网络也不稳。7×24 小时在线的服还是得放机房。
